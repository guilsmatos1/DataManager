# Testing

_Generated by gsd:map-codebase — 2026-03-28_

## Framework & Runner

- **Framework**: pytest
- **Runner**: `uv run pytest`
- **Coverage**: pytest-cov (built into addopts)
- **Mutation testing**: mutmut (targets `components/`)

## pytest Configuration

From root `pyproject.toml`:

```toml
[tool.pytest.ini_options]
addopts = "--import-mode=importlib --cov=components --cov-report=term-missing"
testpaths = [
    "components/datamanager/test",
    "components/portifoliomaster/test",
    "components/tradingmonitor/test"
]
pythonpath = [
    "components/datamanager/src",
    "components/tradingmonitor/src",
    "bases/datamanager_api/src",
    "bases/datamanager_cli/src",
    "bases/trading_monitor_dashboard/src",
    "bases/trading_monitor_cli/src",
    "components/portifoliomaster/src",
    "bases/portifolio_master_cli/src",
    "components/backtestengine/src",
    "bases/backtest_engine_cli/src",
    "components/core/src",
    "components/mt5/src"
]
markers = [
    "integration: marks tests that require a real database (deselect with '-m not integration')",
]
```

**Key notes:**
- `--import-mode=importlib` avoids `__init__.py` conflicts in the Polylith namespace
- Coverage is measured across all `components/`
- Bases are in `pythonpath` so tests can import them without installing

## Running Tests

```bash
# All tests
uv run pytest

# Single file with verbose output
uv run pytest components/tradingmonitor/test/trademachine/tradingmonitor/unit/test_calculator.py -v

# Skip integration tests (require real PostgreSQL)
uv run pytest -m "not integration"

# Run only integration tests
uv run pytest -m integration

# With coverage report
uv run pytest --cov=components --cov-report=html

# Mutation testing
uv run mutmut run && uv run mutmut results
```

## Test Directory Structure

Tests mirror the `src/` hierarchy and live under each component's `test/` directory:

```
components/<name>/test/trademachine/<name>/
├── __init__.py
├── conftest.py             # Component-level fixtures
├── unit/                   # Pure function tests (no I/O)
│   ├── test_calculator.py
│   └── test_*.py
├── service/                # Integration tests with SQLite DB + TestClient
│   ├── test_routes.py
│   ├── test_processors.py
│   └── test_*.py
└── e2e/                    # End-to-end tests against real PostgreSQL
    └── test_api_flow.py
```

**Bases** have minimal test stubs:
```
bases/<name>/test/trademachine/<name>/
└── test_core.py            # Minimal smoke tests
```

## conftest.py Files

### Root `conftest.py`
Located at repo root. Minimal — primarily sets up path resolution for the workspace.

### `components/tradingmonitor/test/.../conftest.py`
The most comprehensive fixture file. Key patterns:

```python
# Environment setup MUST happen before any app module imports
os.environ["API_KEY"] = "test-api-key-pytest"
os.environ["DATABASE_URL"] = "postgresql://postgres:password@localhost:5433/trademachine.tradingmonitor_test"

# Safety guard: never run against production DB
_db_url = os.environ.get("DATABASE_URL", "")
if "trademachine.tradingmonitor_test" not in _db_url and ":memory:" not in _db_url:
    raise RuntimeError("CRITICAL: Tests attempting to run against production DB")
```

**SQLite compatibility shims** (for service tests):
```python
def _patch_sqlite_jsonb():
    """JSONB → JSON for SQLite DDL compatibility"""
    SQLiteTypeCompiler.visit_JSONB = SQLiteTypeCompiler.visit_JSON

def _patch_sqlite_biginteger():
    """BigInteger → INTEGER for SQLite autoincrement compatibility"""
    ...
```

**Key fixtures**:
- `db_session` — SQLite in-memory session with all tables created; auto-rollback after each test
- `test_client` — FastAPI `TestClient` with `db_session` dependency override
- `pg_session` — Real PostgreSQL session; test skipped if DB not available

### `components/datamanager/test/.../conftest.py`
Provides fixtures for datamanager tests. Includes database session setup and mock data helpers.

## Mocking Strategy

- **Primary**: `unittest.mock` (`MagicMock`, `AsyncMock`, `patch`)
- **Secondary**: `pytest` `monkeypatch` for environment variables and module-level patching
- **FastAPI**: `app.dependency_overrides` to inject test DB sessions

```python
# FastAPI dependency override pattern
@pytest.fixture
def test_client(db_session):
    def override_get_db():
        yield db_session
    app.dependency_overrides[get_db] = override_get_db
    return TestClient(app)
```

## Assertion Patterns

| Pattern | Usage |
|---------|-------|
| `pytest.approx(value, rel=1e-6)` | Float comparisons (Sharpe, drawdown) |
| `math.isinf(result)` | Check for infinite values (division by zero scenarios) |
| `pytest.raises(ExceptionType)` | Expected exception testing |
| `assert response.status_code == 200` | FastAPI endpoint responses |

## Test Environment Setup

1. **Env vars before imports**: Set `API_KEY`, `DATABASE_URL` at module top before any app code loads (pydantic-settings reads at import time)
2. **SQLite shims**: Apply JSONB→JSON and BigInteger→INTEGER patches for service-level tests
3. **PG guard**: Hard check that `DATABASE_URL` contains `_test` or `:memory:` — prevents accidental production DB writes
4. **Import mode**: `importlib` mode avoids namespace conflicts in the `trademachine.*` Polylith layout
