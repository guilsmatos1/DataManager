## Test Organization

Tests live alongside each component/base under `test/`:

```
components/<name>/test/trademachine/<name>/
├── conftest.py             # Fixtures (db_session, test_client, etc.)
├── unit/                   # Pure function tests (no DB)
│   ├── test_calculator.py
│   └── test_*.py
├── service/                # Service-level tests (SQLite in-memory DB)
│   ├── test_routes.py
│   └── test_*.py
└── e2e/                    # End-to-end tests (real PostgreSQL)
    └── test_api_flow.py
```

| `projects/datamanager/alembic.ini` | Alembic DB migration config |

## Naming Conventions for Directories/Files

- **Bases**: `snake_case` (e.g., `datamanager_api`, `trading_monitor_cli`)
- **Components**: `snake_case` (e.g., `datamanager`, `tradingmonitor`)
- **Python files**: `snake_case.py`
- **Test files**: `test_<module_name>.py`
- **Config**: `config.py` inside `core/` subpackage
- **Exceptions**: `exceptions.py` inside `core/` subpackage
- **Service logic**: grouped in `services/` subpackage
- **DB code**: grouped in `db/` subpackage (models, storage/repository, database)

## Where to Add New Code

| Type | Location |
|------|---------|
| New reusable business logic | `components/<relevant>/src/trademachine/<name>/` |
| New API endpoint | `bases/datamanager_api/src/trademachine/datamanager_api/router.py` |
| New CLI command | Relevant base `cli.py` or `main.py` |
| New metric plugin | `components/tradingmonitor/src/.../metrics/plugins/` |
| New data fetcher | `components/datamanager/src/.../fetchers/` |
| New DB migration | `projects/datamanager/alembic/versions/` |
| New scheduled job | `metadata/scheduler_jobs.json` + `services/scheduler.py` |
